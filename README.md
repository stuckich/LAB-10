\# Проект обработки матриц и числового ввода



\## Описание структуры проекта

\- `main.py` — основной исполняемый файл, управляющий вводом данных, вызовом функций чтения, анализом и записью отчета.

\- `files\_lab.py` — модуль с функцией `read\_matrix(path)` для чтения и валидации матриц из текстовых файлов.

\- `table.py` — модуль с функциями расчета сумм строк/столбцов и индивидуальной логикой обработки элементов матрицы.

\- `matrix.txt` — входной файл с матрицей (кодировка UTF-8).

\- `report.txt` — результирующий файл отчета.



\## Задание 1: Надежный ввод размера (`read\_positive\_integer`)

Функция запрашивает ввод целого числа до тех пор, пока не будет получено значение строго больше нуля.

\- Обрабатывает нечисловые строковые значения (вывод: `"Не целое число"`).

\- Обрабатывает неположительные числа `<= 0` (вывод: `"Должно быть больше нуля"`).

\- \*\*Пример проверки последовательности ввода:\*\*

&#x20; - `abc` -> ошибка, повтор ввода

&#x20; - `0` -> ошибка «Должно быть больше нуля», повтор ввода

&#x20; - `-2` -> ошибка «Должно быть больше нуля», повтор ввода

&#x20; - `3` -> успешный возврат числа `3`.



\## Задание 2: Чтение матриц (`read\_matrix`)

Функция `read\_matrix(path)` считывает матрицу из файла:

\- Первая строка содержит два целых числа: количество строк и столбцов.

\- Последующие строки содержат элементы матрицы.

\- Проверяются: пустой файл, некорректный заголовок, неверное количество строк/столбцов, нечисловые значения в ячейках. При ошибках генерируется `ValueError` с описанием.



\## Задание 3: Обработка и формирование отчета

В `main.py` реализована безопасная работа с файлами:

\- Перехват исключений `FileNotFoundError`, `UnicodeDecodeError`, `PermissionError` и `ValueError`.

\- Запись результатов в `report.txt`. Существующий входной файл (`matrix.txt`) никогда не открывается в режиме записи (`'w'`).
